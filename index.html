Works with /details/, /download/, /metadata/, or a bare identifier. Uses the public archive.org/metadata/<id> API — no key, no server, runs in your browser.
To download a file: right-click its link → Save link as…  ·  this page cannot fetch the bytes itself, because archive.org redirects to a storage node that sends no CORS headers.
